# Ремикс `_handsgod.mp3` — max-версия

150 BPM, новые барабаны, живой бас-грув, пэды, FX и клубная аранжировка.
Собрано кодом (numpy/scipy/librosa): анализ исходника → синтез партий → микс → мастер.

## Что добавлено

**Барабаны**
* Кик-слой: синтезированные кики, **поктактовая настройка в корень** (кит из 12 питч-классов,
  база 49 Гц = G1); садятся на кики исходника (±3 мс), в дропах добирается сетка 16-ми,
  слабые восьмые тише — появился грув.
* Клэпы и снейр на 2 и 4, форшлаги-клэпы перед филлами.
* Хэты 8/16, открытый хэт на «и», шейкеры, **ратчет-роллы** каждые 8 тактов.
* Том-филлы и снейр-роллы в конце фраз.

**Бас**
* Суб-слой: суб-октава низа исходника + чистый синус по f0 (там, где бас есть).
* **Мид-бас-грув** в тактах без баса: плак-бас (пила+квадрат, затухающий ФНЧ) по корню секции —
  и суб-дубль октавой ниже. Дырки 40–50 c и 83–87 c стали дропами: **+7.5 дБ саба**.
* Бас-стабы в брейках, 16-е призвуки на «и».

**Гармония и атмосфера**
* Пэды в брейкдаунах (3 расстроенные пилы + квинта, медленный фильтр) по корню секции.
* Стабы-хуки из срезов самого трека с пинг-понг-дилеем.

**FX и переходы**
* Райзеры (с тональным слоем), импакты, **саб-дропы**, реверс-крэши, даунлифтеры.
* «Всасывание» перед дропами (пауза 1/8), дроп-ауты, beat-repeat-стуттеры (24/51/94 такты),
  tape-stop в конце.
* **DJ-интро 12.7 c** (LP-луп + реверб + свои барабаны) — ремикс влезает в сет.
* **Аутро-луп** 6.4 c вместо обрыва в тишину.

**Микс и мастер**
* Шины: дакинг исходника и баса под кики, компрессия драм-шины, сатурация баса, HP 28 Гц.
* Мастер: M/S-ширина (низ в моно), клей-компрессор, ленточная сатурация (чётные гармоники),
  лимитер, LUFS-калибровка, true-peak нормализация.

## Пересборка

```bash
# из корня репозитория
python3 -m venv .venv
.venv/bin/pip install -r remix/requirements.txt

.venv/bin/python work/harm.py        # HPSS-кэш (work/perc.npy, work/harm.npy), ~25 c
.venv/bin/python remix/make_remix.py # ремикс целиком, ~70 c

.venv/bin/python work/qa.py          # метрики (LUFS/TP/полосы/клики)
.venv/bin/python work/figures.py     # картинки
```

Если кэша `work/*.npy` нет — `make_remix.py` сам пересчитает HPSS.

**Ручки** (в начале `remix/make_remix.py`): `PRE_BARS` (длина интро), `TARGET_LUFS`,
`targets` (баланс слоёв), списки `DROPS` / `BREAKS` / `RISERS` / `FILL_BARS` / `RATCHET_BARS`,
`NOBASS` (где включается мид-бас-грув), `PAD_BARS`, `RADIO_BLOCKS`.

## Ограничения — честно

* **Вокал не отделён.** В песочнице нет доступа к весам demucs/HDemucs (GitHub release-assets
  заблокирован), spleeter упирается в память (4 ГБ). Поэтому исходник звучит целиком:
  обработанный, с дакингом, но вокал с музыкой вместе. Полный «акапелла-ремикс» тут не собрать.
* Кик/клэп/хэты — синтез (numpy/scipy), не сэмплы 909-й серии. Параметры синтеза вынесены
  в аргументы `dsp.kick`, `dsp.clap`, `dsp.snare`, `dsp.bass_pluck` — можно перекрутить вкус.
* Громкость −9.4 LUFS — клубный таргет; p95 ограничения 0.4 дБ, но на пиках лимитер работает
  до 3.4 дБ. Если нужен более динамичный мастер (−10.5…−11 LUFS) — поменять `TARGET_LUFS`.
