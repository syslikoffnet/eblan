# Ремикс `_handsgod.mp3` — 150 BPM, +барабаны, +саб, +FX

Трек прошёл полный анализ (сетка, структура, тональность), после чего к нему дособран
новый слой: барабаны, саб-бас, FX и клубная аранжировка (DJ-интро → дропы → брейки → аутро).

## Что выяснилось про исходник

| Параметр | Значение |
|---|---|
| Темп | **150.000 BPM ровно** (все партии — кик, саб, снейр, хэты, лид — стоят на одной 8-й сетке) |
| Бит / такт | 400 мс / 1.600 с |
| Фаза сетки | первый даунбит на 0.084 с, дальше метроном (за 174 с — ноль дрейфа) |
| Тональность | ползает: C / G / F# пласты, стабильного центра нет (по барам корни прогоняются отдельно) |
| Структура | интро 0–11 c; дроп 11–37; брейк 37–40; **40–50 — кики без баса**; дроп 50–64; брейк 64–65; дроп 65–77; брейкдаун 77–83; **83–87 — кики без баса**; дроп 88–102; брейки 102–104, 118–120; дроп 120–140; брейкдаун 140–147; дроп 147–166; аутро 166–174, тишина с 167.5 |
| Слабые места | нет нижнего баса в 40–50 c и 83–87 c; кики «плоские» (0.1 dB контраста фазы в 4/4), хэты размазаны, нет FX-переходов |

## Что добавлено

* **Кик-слой** — синтезированные кики (питч-огибающая 210→47 Гц, сатурация) ставятся
  ровно на кики исходника (`±3 мс`), а в дропах добирается сетка 16-ми; на слабых
  восьмых громкость ниже — получается нормальный грув вместо ровного «молотилова».
* **Клэп + снейр** на 2 и 4 (`−8.5 dB`), слой снейра в брейках.
* **Хэты 8/16-ми, открытый хэт на «и», шейкеры** — верхняя динамика.
* **Том-заполнения и снейр-роллы** в конце фраз (каждые 8 тактов).
* **Саб-бас** — два слоя: суб-октава низа исходника (питч −12 пт, 27–95 Гц) + чистый
  синус по f0 исходника, зафиксированный по полутонам. В барах 25–30 и 52–54, где у
  исходника **нет баса**, играет отдельный мид-бас-синус по тонике бара, в ритме киков —
  эти «дырки» стали полноценными дропами.
* **FX**: райзеры перед каждым дропом, реверс-крэши, импакты и даунлифтеры на границах,
  белые шумы; срезы исходника как стабы-хуки (такты 42–47 и DJ-интро) с пинг-понг-дилеем.
* **DJ-интро 12.7 c**: луп из дропа исходника, уведённый LP до 420 Гц + реверб, поверх —
  свой кик 4/4, хэты, клэп, ролл и райзер. Подходит для сведения в клубный сет.
* **Обработка исходника**: автоматизированные LP/HP-свипы по секциям, дроп-ауты,
  beat-repeat-стуттеры (такты 24, 51, 94), tape-stop в конце, сайдчейн под кики (−3 дБ).
* **Аутро**: 6.4 c луп-хвост из финального дропа вместо обрыва в тишину.
* **Мастер**: DC-блок → EQ (низ +2.5 дБ, чистка 350 Гц, верх +1.5 дБ) → клей-компрессор
  1.6:1 (20 %) → параллельная сатурация → M/S-ширина → лимитер → true-peak-нормализация.

## Как пересобрать / покрутить

```bash
# всё запускается из корня репозитория (скрипты ищут _handsgod.mp3 и work/ относительно него)
python3 -m venv .venv && .venv/bin/pip install -r remix/requirements.txt

# 1) анализ исходника -> work/perc.npy (перкуссия) и work/harm.npy (гармоника)
.venv/bin/python work/harm.py

# 2) сборка ремикса ~55 c, пишет в remix/
.venv/bin/python remix/make_remix.py

# 3) отчётные фигуры и проверки (опционально)
.venv/bin/python work/figures.py && .venv/bin/python work/final_check.py
```

Основные «ручки» — в начале `remix/make_remix.py`:

* `PRE_BARS` — длина DJ-интро (8 тактов = 12.7 c);
* `targets` в `main()` — баланс слоёв относительно исходника (`drums 0.70`, `subs 0.46`, …);
* `TARGET_LUFS` — целевая громкость мастера (−10.0 LUFS);
* списки `DROPS`, `BREAKS`, `RISERS`, `FILL_BARS` — аранжировка в тактах исходника;
* `KICK_EIGHTHS` — где кик идёт 8-ми (все дропы) — можно оставить 4/4 в брейкдауне.

## Честные ограничения

* Разделения на вокал/инструментал здесь нет: в песочнице нет доступа к весам demucs/HDemucs,
  поэтому «поверх нового бита оставить только вокал» пока нельзя. Вместо этого исходник
  обрабатывается целиком (фильтры/сайдчейн), что даёт более плотный «ремикс для клуба»,
  но вокал и музыка слышны вместе. Если нужен вариант «вокал + новый бит» — подключим
  stem-splitter (demucs) и пересоберём за один прогон, тогда саб/бас от исходника
  убираются полностью и остаётся чистый акапелла-слой.
* Все синтезированные партии сгенерированы кодом (numpy/scipy): кик — питч-огибающая +
  клик + сатурация, клэп — 5 щелчков с разбросом, хэты — шум + металлические партиалы.
  Это не сэмплы 909-й серии, но по спектрам и динамике сведено «в клубной» зоне;
  если нужен другой флейвор (бочка длиннее/мягче, снейр с румом) — параметры синтеза
  (`dsp.kick`, `dsp.clap`, `dsp.snare`) вынесены в аргументы.
