## Гармония (A minor)

```
| Am | F  | C  | G  |   × повторы
A1   F1   C2   G1       — бас (оффбит-слэп: корень / квинта / октава)
```

Хук (плак + голос): `A4 C5 E5 C5 | A4 C5 F5 C5 | G4 C5 E5 C5 | G4 B4 D5 B4`.

## Вокал

* **Голос** — TTS-спикер (voice-00), вокальная цепочка: HP 95 Гц → срез 320 Гц →
  презенс 2.8 кГц → де-эссер 5.5–9.5 кГц → сатурация → компрессия 3.2:1.
* Фразы подстроены в A-moll (питч-шифт +2 пт) и посажены точно в такт.
* **Формантный слой** — синтезированный «певец»: глоттальный источник (пила с вибрато
  и джиттером) → 4 резонатора F1–F4 по гласной → буст 2.9 кГц.
  Поёт ноты хука, даблы октавой выше — всегда в тональности.
* **Эдлибы** «Громче! Ярче! Ещё!» нарезаны на 3 возгласа и раскиданы по 8-м.
* **Чопы** — первый слог хука повторяется на 16-х (тот самый «TikTok-стаб»).

## Микс и мастер

* Драм-шина: HP 30 Гц, компрессия 2.2:1 (30 %).
* Бас: HP 30 Гц, буст 120 Гц, сатурация; сайдчейн −4 дБ.
* Аккорды/плак: сайдчейн −7 / −3 дБ; пэды −5 дБ.
* Реверб-сенд (1.8 c) на вокал и плак.
* Мастер: DC → EQ (низ +2.2, срез 340 Гц, верх +1.6) → M/S-ширина → клей 1.5:1 →
  ленточная сатурация → лимитер → LUFS/true-peak.

| метрика | значение |
|---|---|
| Интегральная громкость | **−8.4 LUFS** |
| True peak | **−0.30 dBTP** |
| Сэмпловый пик | 0.841 (без клиппинга) |
| Динамика по секциям | дроп −8.1…−8.4 / брейк −8.3 / аутро −13.9 LUFS |
| Темп | 128.0 BPM, сетка построена программно (без дрейфа) |
| Тональность | A minor |

## Как сделать вирусный ролик

1. Возьми `tiktok_15s.mp3`: 0:00–0:03 текст хука, 0:03.75 входит бит, 0:07.5 дроп.
2. Субтитры — из `track/lyrics.txt` (там тайм-коды).
3. Вертикальное видео 9:16: обложка `cover_final.png` как фон/заставка, или кадры
   «ночной город / наушники / неон».
4. Первые 2 секунды — самый цепкий фрагмент текста («Этот сигнал только для тебя»),
   без логотипа и пустых кадров.
5. Повтор-пост: тот же 15-секундный фрагмент с другим визуалом — алгоритм любит репетицию.

## Честно про «идеальный вокал»

Голос здесь — **TTS-спикер, а не певец**: он говорит ритмично и точно в тональности,
но не тянет ноты с вибрато и не звучит как живой вокалист. Формантный синтез даёт
мелодического «певца», но тембр синтетический (это слышно). Настоящий вокальный
продакшен требует записи живого голоса или модели вроде Suno/Udio — в этой песочнице
доступа к ним нет. Всё остальное (бит, бас, гармония, структура, микс, мастер,
обложка, нарезки) — полностью готово и подставляется под любой вокал.
